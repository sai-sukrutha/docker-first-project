*** 03_02 ***

We can view the images present locally(downloaded) using -
docker image ls
docker image ls [OPTIONS] [REPOSITORY[:TAG]]

docker image ls --all

docker image ls --no-trunc      (no truncations - shows full ids etc.,)

docker image ls --quiet        (only image ids - hiding all other details)

docker image ls --digests       (includes image digest(hash -sha) column)

We can also use --filter in this command but differnt options here
docker image ls --filter reference=python*      (reference - filter with name or tag)

docker image ls --filter before=python          (shows images created before an image)

docker image ls --filter since=python           (shows images created after an image)

docker image ls --filter dangling=true          (dangling - not used, like intermediate)

docker image ls --filter label=python*          (based on image label)

Similarly, we can do format like before, but differnt options
docker image ls --format "table {{.ID}}\t{{.Repository}}\t{{.Tag}}\t{{.Size}}\t{{.CreatedSince}}\t{{.CreatedAt}}\t{{.Digest}}"

docker image ls --help

https://docs.docker.com/engine/reference/commandline/image_ls/
